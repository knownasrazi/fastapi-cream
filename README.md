# fastapi-clean — FastAPI, in clean.

Clean FastAPI starter - minimal, typed, and ready for vibe-coded APIs.

---

## Story

We built fastapi-clean because vibe coding needs tools that respect attention. Not another dashboard. Just a surface to work.

## Architecture

```
fastapi-clean/
  src/        — core logic (Python)
  public/     — static assets
  README.md   — you are here
```

- **Python** — the whole thing
- **Clean** — #fdfcfa background, #1a1a1a ink
- **No framework bloat** — you can read every file in 5 minutes

## Install

```bash
git clone https://github.com/knownasrazi/fastapi-clean.git
cd fastapi-clean
pip install -r requirements.txt
```
