## Why fastapi-cream?

> FastAPI, in cream. - built for vibe coders and web developers who ship with taste.

Cream FastAPI starter - minimal, typed, and ready for vibe-coded APIs. This template keeps the cream aesthetic - stone, ink, and low contrast - and ships with a clean structure you can vibe-code on top of.

## Stack

- **Language:** python
- **Style:** Tailwind cream tokens, Biome where applicable
- **Quality:** CI, lint, and a minimal test harness

## Get started

```bash
git clone https://github.com/knownasrazi/fastapi-cream.git
cd fastapi-cream
```

Language-specific quick start is inside.
